The simplest evolutionary algorithm and the "hello world" of evolutionary computation.

## Evolutionary Lineage
The (1+1)-ES is a foundational algorithm in the **evolution strategies (ES)** family and serves as a building block for more advanced methods. Below is a graph showing its connections to other key algorithms:

```mermaid
graph TD
    A[Evolutionary Algorithms] --> B[Genetic Algorithms]
    A --> C[Evolution Strategies]
    C --> D[(1+1)-ES]
    C --> E[CMA-ES]
    A --> F[Differential Evolution]
    D --> E
```

### Key Connections:
1. **Evolution Strategies (ES)**:
   - The (1+1)-ES is the simplest form of ES, focusing on **mutation** and **elitist selection**.
2. **CMA-ES**:
   - The (1+1)-ES inspired the **step-size adaptation** mechanism in CMA-ES, which extends it with **covariance matrix adaptation** for high-dimensional problems.
3. **Genetic Algorithms (GAs)**:
   - While GAs emphasize **crossover** and **population diversity**, the (1+1)-ES focuses on **mutation** and **single-parent evolution**.
4. **Differential Evolution (DE)**:
   - DE is another continuous optimization algorithm, but it relies on **vector differences** rather than mutation strength adaptation.

## Core Idea
- **Population of 1**: A single parent solution.
- **Mutation only**: Create one offspring by randomly perturbing the parent.
- **"+" selection**: The offspring replaces the parent only if it is at least as good.

### Algorithm
```text
x = random solution
while not done:
    y = mutate(x)
    if fitness(y) <= fitness(x):   # minimization
        x = y
```

### Notation: (μ + λ) vs (μ, λ)
- **(μ + λ)**: The next generation is chosen from parents and offspring combined (elitist; the best solution can never be lost).
- **(μ, λ)**: The next generation comes from offspring only (parents always die; helps escape local optima).
- **(1+1)**: 1 parent produces 1 offspring, and the better of the two survives.

### Why It’s Interesting
- **Simplicity**: Despite its minimalism, it works surprisingly well. For example, on the OneMax problem, it finds the optimum in expected **O(n log n)** mutations.
- **Theoretical Foundation**: It’s the standard testbed for evolutionary algorithm runtime analyses.
- **Modern Descendants**: The (1+1)-ES with success-based step-size adaptation (e.g., the **1/5th rule**) led to algorithms like **CMA-ES**, the go-to method for real-valued black-box optimization.

### Applications
- Theoretical studies and benchmarking.
- Optimization problems where simplicity and speed are critical.
- Foundation for more advanced evolutionary strategies.
